# 桌面端会话切换器收起态设计

## 状态

已确认。本设计补充 `2026-07-27-conversation-switcher-design.md`，仅调整会话切换浮层的定位、默认状态和视觉密度，不改变会话列表、分页、缓存及切换逻辑。

## 目标

桌面端会话切换器默认以一列状态条收起在视口右侧。鼠标移入或键盘焦点进入后，浮层向左展开为完整会话列表；离开后恢复收起状态。收起态只展示状态条，降低对聊天内容的遮挡。

## 交互与定位

- 切换器使用 `position: fixed`，位于视口右侧并垂直居中，脱离聊天区布局和滚动容器。
- 默认收起，只显示所有会话对应的状态条，不显示标题、面板背景、边框或阴影。
- 鼠标进入状态条区域时展开整个列表；鼠标离开后自动收起。
- 键盘焦点位于切换器内部时保持展开，确保 Tab、Enter 和 Space 操作可用。
- 点击条目、分页加载、激活项自动滚入可视区域等原有行为保持不变。
- 移动端仍不渲染该切换器。

## 视觉

- 激活项状态条固定为 `21×6px`，使用从 `#96C0FF` 到 `#8686FF` 的横向渐变。
- 普通非激活项状态条固定为 `15×6px`，颜色为 `#C5C5C5`。未读和加载状态也使用 `15×6px`，但继续保留各自颜色或动画。
- 状态条按设计标注使用直角矩形，不设置圆角。
- 展开态沿用当前浅色、深色卡片样式。每个条目最小高度固定为 `30px`，标题字号固定为 `15px`，在保持可读性的同时压缩纵向间距。
- 展开面板从右向左显现，状态条始终靠近视口右侧，避免鼠标移动过程中触发区域断开。
- 展开和收起使用轻量的宽度、透明度及阴影过渡；`prefers-reduced-motion: reduce` 下取消过渡。

## 实现边界

- 优先使用 CSS `group-hover` 与 `group-focus-within` 表达展开状态，不新增 React 交互状态。
- `ConversationSwitcher` 保持现有数据与滚动逻辑，只调整 DOM 包装和样式。
- `ChatArea` 不再因切换器预留大块右侧空间，恢复桌面端基础内容边距；浮层允许覆盖右侧少量内容。
- 收起态仍渲染可访问的原生按钮，文字通过视觉隐藏而非移除，保留条目的无障碍名称。

## 验证

- 桌面端初始只显示状态条；激活条为 `21×6px`，普通非激活条为 `15×6px`。
- 悬停任意状态条后完整面板稳定向左展开，鼠标在面板内移动不会意外收起。
- 移出面板后恢复收起态；键盘焦点进入时保持展开。
- 展开态条目最小高度为 `30px`、标题字号为 `15px`，长标题仍单行省略。
- 浅色、深色主题下状态清晰，未读、加载、错误、分页及会话切换行为无回归。
- 窗口和消息区滚动时切换器保持视口右侧居中。
- 系统减少动态效果开启时无明显展开或收起动画。
- `npm run lint` 与 `npm run build` 通过。

## 验收标准

- 默认收起态只显示全部会话状态条。
- 悬停或键盘聚焦后呈现完整列表。
- 切换器为 fixed 浮层，不占据聊天区文档流。
- 激活条为 `21×6px` 紫蓝渐变矩形，普通非激活条为 `15×6px`、`#C5C5C5` 灰色矩形。
- 展开态条目最小高度为 `30px`，标题字号为 `15px`。
